# Release v1.0.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v1.0.2 — finalize CHANGELOG, align README assertion counts, and tag via `tools/tag-release.sh`, with zero code changes.

**Architecture:** Two manual doc commits (CHANGELOG, README), then the repo's release script does the version bump + annotated tag, then manual push and CI verification. Spec: `docs/superpowers/specs/2026-10-22-release-v1.0.2-design.md`.

**Tech Stack:** Markdown docs, bash release script, git tags, `gh` CLI for post-push verification.

**Hard constraints (spec §1):**
- `src/` and `include/` zero-line diff across the entire release.
- Never delete a pushed tag; post-push defects ship as 1.0.3.
- Conventional Commits with gitmoji.
